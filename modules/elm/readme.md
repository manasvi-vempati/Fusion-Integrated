**Title:** Implement Employee Leave Management (ELM) Module

**Description:**

## Overview
Adds the Employee Leave Management module to Fusion-Integrated as a separate module, preserving existing modules.

## Changes
- Implement leave application creation, submission, and status tracking.
- Implement leave balances and balance transaction records.
- Add permission checks for applicants, reviewers, and authorized administrators.
- Integrate ELM with the existing backend, frontend, routing, and database architecture.
- Add tests for validation, authorization, and leave workflows.
